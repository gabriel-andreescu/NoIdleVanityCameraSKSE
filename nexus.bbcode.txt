[size=4][color=#00ffff]OVERVIEW[/color][/size]
[size=3]Very lightweight SKSE plugin that completely disables the idle rotating camera around the player character.
Works on new and existing saves.[/size]

[size=4][color=#00ffff]ALTERNATIVE[/color][/size]
[size=3][url=https://www.nexusmods.com/skyrimspecialedition/mods/61539]Disable Auto Vanity Mode[/url] - ESPFE alternative that changes INI settings. On existing saves it pushes the delay to 1 hour, on a new game it disables the vanity camera.[/size]
[url=https://www.nexusmods.com/skyrimspecialedition/mods/131350]Sandbox When Idle[/url] - Instead of spinning camera, player now sandboxes if game is idle for too long.
